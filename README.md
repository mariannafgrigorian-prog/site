# Ярмарка страхов

## О проекте

«Ярмарка страхов» — авторский веб-проект, представляющий страхи в формате необычной ярмарки, где каждый страх становится товаром. Концепция проекта объединяет веб-дизайн, графические образы и нестандартную подачу привычного интернет-магазина.

## Использование искусственного интеллекта

В процессе разработки проекта я использовала искусственный интеллект ChatGPT в качестве вспомогательного инструмента для решения отдельных технических задач.

Основным направлением использования ИИ стала **адаптация сайта под экраны разных размеров**. С его помощью я работала над адаптивностью страницы, чтобы сайт корректно отображался не только на экране компьютера, но и на планшетах и мобильных устройствах.

ИИ помогал мне искать решения для изменения расположения элементов, настройки размеров блоков и текста, а также улучшения отображения изображений и других компонентов интерфейса на экранах с разным разрешением.


Результаты предложенных решений использовались как вспомогательная основа для работы над адаптивной версией сайта. При этом я самостоятельно работала над проектом, его концепцией, визуальным стилем и общей структурой.

## Технологии

- **HTML** — создание структуры сайта.
- **CSS3* — оформление страниц, работа с типографикой, цветами и расположением элементов.
- **Git и GitHub** — хранение исходного кода и отслеживание изменений.

## Цель проекта

Создать оригинальный веб-сайт с выразительным визуальным стилем и необычной концепцией, объединив графический дизайн и веб-разработку.
